# Poor Man's DAGitty

Sometimes I want to sketch a causal diagram and check the backdoor paths without opening the full DAGitty. This is that: one HTML file, no dependencies, no build step.

Open `index.html` in a browser. Draw your DAG, mark the exposure and outcome, and it works out backdoor paths and adjustment sets, and shows descendants of a node.

Vanilla HTML/CSS/JS. It does less than DAGitty and that's the point.
